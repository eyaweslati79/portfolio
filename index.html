Stage chez TELNET · juillet à septembre 2026 · réalisé seule

Chatbot EMV : poser une question à 558 pages de spécifications

Les développeurs et nouveaux arrivants perdaient du temps à chercher dans la documentation technique EMV. J'ai conçu un assistant qui répond en citant ses sources, et qui refuse de répondre quand la question sort de la documentation.

  • Pipeline documentaire complet : extraction PDF, découpage, embeddings, recherche vectorielle dans Qdrant, génération par un LLM.
  • API REST Java/Spring Boot de 22 endpoints, service IA en Python/FastAPI, interface Angular, MongoDB.
  • 100 tests automatisés et un jeu de 30 questions pour mesurer la qualité des réponses.

Spring Boot · FastAPI · Angular · MongoDB · Qdrant · LLM · Docker

Code privé, propriété de l'entreprise.
